## 2. 开工前需求确认

- 已调查事实：赛博/霓虹下搜索胶囊为浅色玻璃，SPEC-265 强制白字导致占位/AI 助手/图标几乎不可见。
- Agent 最终复述：胶囊内按胶囊底选深/浅字；赛博/霓虹用深色；壁纸上 logo/书签名仍可按壁纸深浅。
- 任务下达者确认：2026-11-19「确认」
- 确认后需求变化：无

### 红色问题判定

- 否（局部 NTP 配色，可回退）

## 3. 为什么做

霓虹/赛博主页搜索框白字打在浅色胶囊上无法阅读，需保证可读。

## 4. 本次范围

要实现：

- 搜索胶囊内（占位、AI 助手/无痕、扫码/搜索等）字色/图标按**胶囊底**可读：浅底深字、深底浅字。
- 赛博/霓虹：胶囊内固定深色字与图标（不再用 SPEC-265 浅色）。
- 壁纸上 logo、快捷书签名：保持现有按壁纸深浅（深色预置浅色字）。

明确不做：

- 不改壁纸资源、底栏、资讯卡；不完成 SPEC-268；本轮不强制 assemble。

## 5. 用户如何使用

1. 选择赛博或霓虹壁纸进入主页。
2. 搜索框内占位与操作文案/图标为深色，清晰可读。
3. 快捷方式标签仍为浅色（压在深色壁纸上）。

## 6. 产品规则

- 当壁纸为赛博/霓虹时，搜索胶囊内墨色必须为深色。
- 当胶囊底（fieldBg）相对亮度 ≥ 阈值时，胶囊内必须用深色墨；否则用浅色墨。
- 系统不得再因「深色预置壁纸」单独把胶囊内强制为白色。

## 7. 验收标准

- [ ] AC-01：赛博壁纸下，搜索占位与第二行「AI 助手」等为深色，对比可读。
- [ ] AC-02：霓虹壁纸下，同上。
- [ ] AC-03：无深色预置、深色主题（深色 fieldBg）时，胶囊内仍为浅色字（不误伤）。
- [ ] AC-04：单元测试覆盖 `useDarkCapsuleInk` 决策。
