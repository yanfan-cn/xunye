## 用户问题

1. **手势切回闪退（仅 release 1.0.1/1.0.2）**：从其他 App 用系统导航手势切回巡页即闪退；停在浏览器主页不闪，停在其他页/浏览网页必闪。手机与平板均有。debug 未复现，怀疑与 release/R8 或内核生命周期有关。
2. **平板标签串内容**：来回点击顶部标签栏，所有标签页变成相同网页内容。
3. **启动恢复丢前进/后退**：开启「启动时恢复上次浏览」后，恢复的页没有前进/后退栈，返回直接到浏览器主页；且已在主页时标签名仍显示原网页标题。
4. **系统分享文案与收藏**：分享面板显示「阅读 · 搜索」；改为「巡页·搜索」，并新增「巡页·收藏」（有有效链接才收藏，否则提示无法收藏；不支持纯文本标题+链接一并收藏）。

## 范围

1. **切回闪退**：Activity/进程前后台切换时，对活跃 AwContents 正确 `onPause`/`onResume`；巩固已知液态玻璃叠内核风险；以 release 真机验收为准。
2. **平板标签串页**：标签元数据更新与会话回调按 tab/sessionKey 门闩，避免切标签时把 A 页 URL 写进 B 并 `loadUrl` 污染已 park 的内核页。
3. **恢复历史**：持久化各标签 WebView/AwContents 导航状态（`saveState`/`restoreState`）；冷启恢复优先还原后退/前进栈；`showHome` 时标签展示名固定为「新标签页」（不显示旧网页标题）。
4. **分享**：主包/各 locale 文案改为「巡页·搜索」；新增「巡页·收藏」入口：从分享文本提取首个 `http(s)` 链接加入浏览器收藏，无有效链接则提示无法收藏后结束。
5. **Release**：仅 `assembleAlohaRelease` → `巡页1.0.3.apk`（本包 1.0.3 / code 4，构建后 bump）；不同次 debug。

## 非目标

- systemWv release；同次 debug。
- 无 tombstone 时不做无证据的大范围玻璃重构。
- 分享收藏不解析「标题 + URL」双字段；不做阅读书签（仅浏览器收藏）。
- 不改变「启动时恢复上次」开关默认值。
