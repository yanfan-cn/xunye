## 3. 为什么做

翻译路径需统一为「本机优先（与 Firefox 同类）+ 可选云端 Google + 可选应用 AI」，去掉大陆网页译依赖与 ML Kit 双轨，便于后续工程选型。

## 4. 本次范围

要实现（文档口径）：

- **默认引擎**：Bergamot（Firefox Translations 同源本机神经翻译）。
- **提供方**：Bergamot、Google 翻译、应用 AI。**去掉**百度翻译、**去掉** ML Kit 端上翻译。
- **仅两处产品能力**（2026-11-07 收窄）：
  1. **浏览器**：类似 Chrome 的实时就地网页翻译（原 URL、改 DOM；恢复 SPEC-085 闸门后的唯一网页译形态）。
  2. **净读**：翻译全文（当前章/当前正文全文，沿既有章节译管线语义）。
- **本轮交付**：本 Spec / Plan / Log + 交接一句；不改代码。
- **工程落地偏好（2026-11-07 追加确认「选A」）**：Bergamot 经 **现成 Android 封装 AAR** 接入（首选评估 **Foxlet**），不自编 Bergamot JNI。

明确不做：

- **整页跳转套壳**（任何提供方）。
- 其它翻译形态（选区译、弹层词典、侧栏对照等）本口径未授权则不做。
- 本轮不接 Foxlet/AAR、不自编 JNI（工程 spike / 实施另开）。
- 不改设置 UI、不改 `WEB_PAGE_TRANSLATE_UI_ENABLED`、不组装 APK。
- 本轮不承诺模型体积、语种覆盖表或默认下载策略（留给 spike）。

## 5. 产品规则

- 用户未改设置时，翻译走 **Bergamot**。
- 选 **Google**：章节正文可出站至 Google；失败须可感知提示。**禁止**用 Google（或其它）整页跳转套壳作为网页翻译手段。
- 选 **应用 AI**：沿用现有应用 AI 接口语义（出站至所配 AI 端点）。
- 选 **Bergamot**：正文留在本机；允许为下载语言模型联网；无模型/不支持语种时须提示，不得静默空译当成功。
- **网页翻译硬禁令（2026-11-07）**：绝对不做整页跳转套壳（如 `translate.google.com/translate?u=`、百度 `fanyi.baidu.com/transpage` 等把当前标签导航到译站包装页）。网页译只允许 **原 URL 页内就地改 DOM**（Chrome 类实时就地译）；恢复 SPEC-085 闸门时不得重新启用套壳路径。
- 产品翻译入口只服务上述两处：浏览器就地译、净读翻译全文。
- 百度、ML Kit 不再作为产品可选提供方（实现阶段再删代码与文案）。
