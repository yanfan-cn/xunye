## 用户问题

1. 浏览器主页进 AI、侧栏切换有内容会话仍卡顿掉帧；2.5.7 无明显改善。
2. 打开侧栏会自动聚焦搜索并弹出输入法。
3. AI 输出时底部（输入胶囊下至屏幕底）有实色空白占位，应为透明（截图确认）。
4. 回答底栏：左侧 token 与右侧刷新/复制应同高；新增「分享」；复制/分享去掉 Markdown 的 `*`、`#` 等标记。
5–6. 省 token / 多模态：本轮仅答复，不实现。

## 范围

1. **流畅**：进 AI 页与切有内容会话减主线程卡顿（消息解码下沉、Markdown 首帧勿同步解析、去掉回答区无谓 `animateContentSize` 等可验证点）。
2. **侧栏**：打开侧栏不自动聚焦搜索、不弹 IME；仅用户点搜索框才聚焦。
3. **底栏**：保留原有底部半透明渐变模糊；去掉输入胶囊下至屏幕底的实色白块占位（截图中的实心条），勿改成完全透明。
4. **操作行**：token 与刷新/复制/分享同一行垂直居中；分享走系统 `ACTION_SEND` 纯文本；复制与分享内容先剥常见 Markdown 标记。

## 非目标

- 不实现发图 / 语音播报等多模态。
- 不做省 token 产品开关。
- 不打 release。
