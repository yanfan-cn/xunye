## 2. 开工前需求确认

- 已调查事实：
  - 浏览器收藏、收藏文件夹、浏览历史全部存在 SharedPreferences `browsesth_browse_store`（JSON 字符串）。
  - `Backup.backupFileNames` 只打包 Room 导出的 JSON 与 `config.xml`；`config.xml` 只导出 `AppConfigStore`（`settings` DataStore）。全局搜索确认 `Backup`/`Restore`/WebDAV 均不引用 `BrowseStore`。
  - 因此现有备份**完全不含**浏览器收藏与历史；备份项里名为「书签」的忽略项指 Room 阅读书签。

## 3. 为什么做

用户换机/重装后，网页收藏与历史目前必然丢失，与「收藏、历史与基础阅读会话管理」的交付承诺不符。

## 4. 本次范围

要实现：

- 备份包新增 `browserBrowse.json`，内容：收藏条目（url/标题/时间/上次打开/文件夹/顺序）、收藏文件夹（id/名称/顺序/父级）、浏览历史条目。
- 恢复时**合并**：本地已有 URL 不覆盖；缺失的收藏、文件夹、历史补入；备份中的文件夹若与本地 id 冲突则分配新 id 并重映射归属。
- 备份忽略项新增「浏览器收藏与历史」（默认参与备份），备份与恢复两侧可分别关闭。
- 超过 `MAX_BOOKMARKS`/`MAX_HISTORY` 时按现有上限截断，并在 Log 记录。

明确不做：

- 不备份密码、自动填充、站点设置、标签页会话、下载记录、搜索历史（`browsesth_search_history`）。
- 不改 WebDAV 通道与压缩格式；不新增导出 HTML 功能。
- 不改阅读书签（Room）既有备份行为。

## 5. 用户如何使用

1. 设置 → 备份与恢复 → 备份（本地或 WebDAV）。
2. 换机后用同一备份恢复：收藏列表（含文件夹层级）与历史记录回来。
3. 若不想备份浏览器数据，在备份忽略项里关闭「浏览器收藏与历史」。

## 6. 产品规则

- 备份包必须包含 `browserBrowse.json`，除非用户关闭该项。
- 恢复必须幂等：同一备份重复恢复不得产生重复条目。
- 恢复不得删除或覆盖用户本地已有的收藏/历史条目。
- 备份/恢复失败不得影响其他数据项；异常写入 AppLog。
