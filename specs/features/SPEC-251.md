## 5. 用户如何使用

1. 打开非目标语言网页 → 工具箱点「翻译」（或平板顶栏翻译键）→ 页内就地译；再点可还原。
2. 长按工具箱「翻译」→ 翻译设置（选提供方/目标语言/两项自动译）。
3. 开启「网页自动翻译」后，打开外文页可自动开译（可感知进度/失败）。
4. 开启「净读自动翻译」后，进净读可自动开全文译。

## 6. 产品规则

- 默认提供方：**Bergamot**；旧百度/ML Kit 偏好迁移到 Bergamot。
- 网页译禁止任何套壳导航；仅页内 DOM。
- 无模型/不支持语向：提示，不得静默空译当成功。
- 自动译默认关；网页与净读开关独立。
- 平板顶栏翻译键：无长按设置行为。
