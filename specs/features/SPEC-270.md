## 3. 为什么做

主页搜索框内文字在部分「主题 × 壁纸 × 表面样式」组合下完全不可读，属于 P1 可用性缺陷；用户已两次反馈同一问题（SPEC-265 → SPEC-269 均只修了一种组合）。

## 4. 本次范围

要实现：

- 搜索胶囊内文字与图标（占位、AI 助手、无痕浏览、扫码、搜索、引擎菜单）按**胶囊实际可见底色**决定深/浅。
- 底色计算必须计入：胶囊填色、液态玻璃透明度（`ntpGlassOverlayAlpha()`）、其下背景（无壁纸=页面底色；浅色预置=实测平均亮度；赛博/霓虹=实测平均亮度；相册/每日壁纸=带遮罩后的深底）。
- 删除「深色预置壁纸 ⇒ 强制深色墨」的绝对分支。
- 对比度不足 4.5:1 时，胶囊自动叠加极薄黑色垫色，把底色推到可用范围，文字始终可读。
- 单测覆盖：深色主题+赛博、浅色主题+赛博、深色主题+浅雾类浅壁纸、填充表面（alpha=1）、中亮度需垫色分支。

明确不做：

- 不改壁纸资源、logo、快捷书签、阅读列表卡、资讯卡配色。
- 不改平板侧栏、网页地址栏（其底色与主题文字色同源，另行观察）。
- 不做「跟随壁纸取色」的主题化改造。

## 5. 用户如何使用

1. 深色主题 + 赛博或霓虹壁纸进入主页：搜索框内为浅色字，清晰可读。
2. 浅色主题 + 赛博/霓虹：搜索框为浅玻璃、深色字，清晰可读。
3. 深色主题 + 浅色壁纸（晨纸/薄雾/窗纱）：搜索框偏浅，自动转深色字。
4. 切表面样式（填充/液态玻璃）后无需重启，配色立即正确。

## 6. 产品规则

- 胶囊内墨色必须由**胶囊实际可见底色**决定，不得由壁纸预设 Id 直接决定。
- 深底（相对亮度低）→ 浅色墨；浅底 → 深色墨。
- 任何组合下，主文字与胶囊底对比度必须 ≥ 4.5:1；不足时系统自行调整底色，不得依赖用户改动设置。
- 同一胶囊内的次要文字与图标与主文字同侧（深墨/浅墨），仅透明度不同。
