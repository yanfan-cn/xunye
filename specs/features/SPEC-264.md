## 用户问题

1. 接入 DeepSeek 后应能正常联网搜索。
2. 简单问题 token 过大（截图：本地工具反复调用）。
3. 流式输出时无法上滑固定，总被拖回底部。
4. 平板正文左右边距不足。
5. 短句用户气泡仍拉满过宽。

## 范围

1. **DeepSeek 联网**：DeepSeek 对话走 Responses；对 **`deepseek-v4-pro`** 默认附带官方 `web_search`（服务端搜索）；**`deepseek-flash` / V4.1 Flash 不附带**（官方忽略）。已有 DeepSeek Chat Completions 配置自动按 Responses 使用。其它厂商本轮不做联网。
2. **省 token**：系统提示禁止通识题乱调本地书架/章节工具；压缩工具回包与相关网页条数/摘要；历史少重复超长工具结果。
3. **滚动**：按距底像素判断贴底；用户上滑后停止跟底，直至回到底部附近。
4. **平板**：消息正文左右 ≥44dp。
5. **用户气泡**：宽度随文本自适应，最大约 86% 屏宽。

## 非目标

- 其它厂商联网、多模态、release、独立「省 token」设置页。
