## 用户问题

1. 1.0.1 release 桌面名变成「巡页Xunye」，应保持「巡页」。
2. 新用户引导「功能介绍」缺浏览器翻译与 AI 助手说明。
3. AI 助手初次保存模型后顶栏仍显示「选择模型」。
4. 净读双击看图缺少双指缩放与「全部照片」入口。
5. 1.0.1 在手机/平板偶发闪退（无 log；印象为频繁切页或连点较快）。
6. 新用户深色模式主页默认壁纸应为霓虹、浅色为薄雾，且不影响日后自选。

## 范围

1. **桌面名**：主包与各中文 locale 的 `app_name` 改为「巡页」（繁体「巡頁」）；Debug 已是「巡页」则对齐即可。文档/宪章产品全称「巡页Xunye」不动。
2. **引导功能介绍**：更新 `onboardingFeatures.md`，新增浏览器翻译与 AI 助手（AI 文案按操作者草稿压缩）。
3. **AI 顶栏**：已配置当前默认模型时显示模型名；无模型才显示「选择模型」。初次向导保存后立即生效。
4. **净读看图**：支持双指缩放；右上角按钮序为 **分享 | Photo Library | 保存 | 关闭**；Photo Library 进入当前页全部图片缩略图，点选跳到对应图。
5. **闪退静态审计**：无 tombstone；针对快切/连点路径检查已知闪退模式（液态玻璃采样、导航竞态、空指针、未附着 Compose、重复 destroy）并加固可确认项；无法确认的标未验证。
6. **NTP 默认壁纸**：仅「从未写入壁纸偏好」的新用户：深色 → 霓虹，浅色 → 薄雾；用户后续切换不覆盖；已有偏好的老用户不变。
7. **Release**：仅 `assembleAlohaRelease` → `巡页1.0.2.apk`（本包 1.0.2 / code 3，构建后 bump）；不同次打 debug。

## 非目标

- 改宪章/对外品牌全称「巡页Xunye」。
- 为闪退做无证据的大范围重构或重开液态玻璃策略。
- systemWv release；同次 debug。
- 漫画阅读器看图（仅净读 `ReaderImageGalleryDialog` 路径）。
