## 用户问题

1. 页内翻译在近期版本极慢（约 1 分钟仍不完整）；早期版本明显更快。
2. AI 助手 UI 需按 DeepSeek 类体验精简顶栏、气泡、横屏分栏与文案。

## 范围

### A. 页内译速度

- 根因：SPEC-255 后 pack **串行**译、丢标记后 **逐节点重试**、中文目标再 **残留拉丁补译**，调用次数爆炸。
- 在保持就地译、禁套壳、尽量完整的前提下：对 pack / 失败节点 / 补译改为 **batch（Bergamot 一次列表；Google 有限并发）**；不改变默认引擎与入口。

### B. AI 助手 UI

1. 顶栏：左上侧边栏（`Menu`）；右上「新建对话」=`Add`、「关闭 AI 助手」=`Close`。
2. 气泡：用户无「你」；AI 不显示模型名与工具调用 UI；思考默认不展开；合并多个「相关书籍」；`origin`/`originName` 为浏览器的条目标题改为「相关网页」。
3. 发送键 icon → `arrow_upward`。
4. 手机/平板 **横屏**：左右分栏；左栏搜索常显、取消侧栏顶栏；右栏对话。
5. 新建对话默认标题「新对话」（不再 `New Chat`）。
6. AI 回答 Markdown 行距统一，消除时大时小。

### C. 交付

- `assembleAlohaDebug` → `巡页2.5.6-beta.apk`。

## 非目标

- 不改翻译产品口径（就地 DOM、禁套壳）。
- 不新增浏览器联网搜索工具。
- 不打 release。
