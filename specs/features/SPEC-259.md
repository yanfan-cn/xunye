2. **手机净读首屏图**：滚动翻页下图片加载完成后须立刻重绘，无需先滑；抽取懒加载属性可小幅加固。
3. **页内翻译**：
   - 文本节点内汉字跳过不送译，英文片段仍译；
   - 去掉 toast「翻译中…」；用净读同款可取消胶囊，文案「翻译中」；点取消中止；净读抽取仍「加载中」。
4. **收藏切换**：工具箱「加入收藏」+ 平板地址栏同键；已收藏 → `bookmark_remove` +「移出收藏」；再点删除该 URL 收藏。
